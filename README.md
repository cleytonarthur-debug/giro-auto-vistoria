# Giro Auto Vistoria

App instalável (PWA) para vistoriar veículos de leilão no pátio: checklist com 2 fotos por item, envio para o Google Drive, preenchimento da planilha do projeto e avaliação por IA.

- `docs/`: o app, publicado pelo GitHub Pages. Funciona sem sinal e se atualiza sozinho.
- O servidor (Google Apps Script) e os dados ficam fora deste repositório. O acesso é feito por um link pessoal com chave.
- `tools/build.mjs` gera os ícones e as fontes. `tools/versao.mjs X.Y.Z "nota"` troca a versão antes de cada publicação.
